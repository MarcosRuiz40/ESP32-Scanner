# ESP32-Scanner
--
Proyecto para adaptar el Port Scanner que tengo programado en RUST a ESP32 utilizando C++
Esta herramienta busca ser un recurso físico y portátil para facilitar tareas de reconocimiento de redes y ejercicios de ciberseguridad.
--

### Objetivos: 
*   Adaptar la lógica de escaneo y manejo de sockets de RUST a las capacidades de red del ESP32.
*   Lograr que el ESP32 sea una herramienta práctica y fácilmente utilizable para el consumidor final.
*   Finalizar el proyecto por completo, documentando el aprendizaje continuo de C++ y el manejo de hardware.
